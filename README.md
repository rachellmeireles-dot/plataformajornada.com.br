# Plataforma Jornada

Versão inicial da plataforma de gestão de apoiadores.

## Recursos desta versão

- Dashboard com total de apoiadores
- Contagem de cadastros realizados no dia
- Contagem de bairros alcançados
- Cadastro de apoiadores
- Pesquisa por nome, telefone e bairro
- Exclusão de registros
- Exportação para CSV
- Layout responsivo para computador e celular
- Armazenamento local no navegador

## Como testar no computador

1. Baixe os arquivos.
2. Abra o arquivo `index.html` no navegador.

## Como publicar na Vercel

1. Envie todos os arquivos para o repositório do GitHub.
2. Entre na Vercel.
3. Clique em **Add New > Project**.
4. Importe o repositório `plataformajornada.com.br`.
5. Em **Framework Preset**, escolha **Other**.
6. Não altere os campos de build.
7. Clique em **Deploy**.

## Atenção

Nesta primeira versão, os dados ficam salvos apenas no navegador do aparelho usado.
Para vários usuários acessarem os mesmos dados, a próxima etapa é integrar o Supabase.
